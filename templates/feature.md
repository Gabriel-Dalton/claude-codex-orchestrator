# Feature task

Read the repository's AGENTS.md and other applicable rules first.

## One job

Describe one feature, its acceptance criteria, and a concrete usage example.

## Limits

Work only in the assigned folder and branch. List interfaces and files that
must stay unchanged. Do not touch other sessions, commit, push, deploy, or
read account secrets. Keep changes limited to the acceptance criteria.

## Finish

Implement the feature and run relevant checks. Add tests for meaningful new
behavior. Review the result against each acceptance criterion.

## Report

Write a short report next to this file with the same stem and .report.md suffix.
Include changes, checks and results, assumptions, and remaining work.
