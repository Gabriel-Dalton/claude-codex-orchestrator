# Review task

Read the repository's AGENTS.md and other applicable rules first.

## One job

Name the diff or component to review and the questions the review should answer.

## Limits

Read only within the assigned folder. Do not edit implementation, touch other
sessions, commit, push, deploy, or read account secrets. The report below is the
only requested file change.

## Finish

Inspect the code and run relevant checks that do not alter shared systems.
Separate demonstrated defects from questions and untested concerns.

## Report

Write a short report next to this file with the same stem and .report.md suffix.
Order findings by severity. Give file locations, evidence, and suggested fixes.
Include checks and results. Say explicitly if no actionable findings were found.
