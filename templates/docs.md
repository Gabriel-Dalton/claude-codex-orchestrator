# Documentation task

Read the repository's AGENTS.md and other applicable rules first.

## One job

Name the document, its audience, and the exact question it should answer.

## Limits

Edit only the named documents in the assigned folder and branch. Preserve
established terminology and links. Do not change implementation, touch other
sessions, commit, push, deploy, or read account secrets.

## Finish

Verify commands and claims against the code. Check links where possible and
read the final document from the reader's perspective.

## Report

Write a short report next to this file with the same stem and .report.md suffix.
Include changed documents, verification, and anything left unverified.
